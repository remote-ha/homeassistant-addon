## English

Secure remote access to your Home Assistant through the Remote HA service.

Try the currently available Pro features for free. This offer applies to new and existing accounts, including accounts whose earlier trial has ended. No card. No automatic charges. We will notify you by email and in your account at least 30 days before early access ends. You will choose whether to subscribe to Pro or continue with Free. We will never start charging you automatically. [Early access terms](https://remote-ha.com/en/early-access).

Requires Home Assistant OS, administrator access and an AMD64 or ARM64 device. HACS and Home Assistant Container do not install this app.

### Register and install

1. Create an account at [remote-ha.com](https://remote-ha.com/en/register) and add your home in the dashboard.
2. Add the official repository to Home Assistant using the button below, or paste its URL into Settings → Apps → Install app → ⋮ → Repositories.
3. Find Remote Home Assistant in the store and select Install.
4. Follow the pairing instructions in your Remote HA account, save the token in the app configuration and start the app. Keep the token private.

A pairing token is created automatically when you add a home and is valid for 120 minutes. The countdown shows the remaining time. After expiry, choose Generate a new token for the same home. Paste it into the app configuration, save and start or restart the app. Do not delete or add your home again.

Säker fjärråtkomst till din Home Assistant via tjänsten Remote HA.

Home Assistant OS, administratörsåtkomst och en AMD64- eller ARM64-enhet krävs. HACS och Home Assistant Container installerar inte den här appen.

### Registrera och installera

1. Skapa ett konto på [remote-ha.com](https://remote-ha.com/sv/register) och lägg till ditt hem i kontrollpanelen.
2. Lägg till det officiella arkivet i Home Assistant med knappen nedan eller ange dess URL under Inställningar → Appar → Installera app → ⋮ → Arkiv.
3. Sök efter Remote Home Assistant i butiken och välj Installera.
4. Följ parkopplingsanvisningarna i ditt Remote HA-konto, spara token i appens konfiguration och starta appen. Håll token hemlig.

En parkopplingstoken skapas automatiskt när du lägger till ett hem och är giltig i 120 minuter. Nedräkningen visar återstående tid. Välj Skapa en ny token för samma hem när den har gått ut. Klistra in den i appens konfiguration, spara och starta eller starta om appen. Ta inte bort ditt hem och lägg inte till det igen.
